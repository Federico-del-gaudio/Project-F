# Fast-Paced Boomer Shooter Rogue-Lite 💥

A high-velocity, stylish boomer shooter featuring rogue-lite elements, modular equipment customization, and dynamic wave-based combat. Focused on fluid mobility, high combat responsiveness, and satisfying game feel.

---

## 🛠️ Current Work & Features

- 🔫 **Modular Weapon System:** Built a flexible weapon framework supporting dynamic attachments, modular stat modifications, and custom firing behaviors.
- 🃏 **Roguelike Card Progression:** Designed and implemented an in-run card selection system to customize player stats, weapon attributes, and combat abilities during gameplay loops.
- 👾 **Wave Management & Enemy Spawner:** Developed a scalable enemy spawner system handling progressive difficulty, wave timing, and encounter density.
- 🔊 **Sound Design & Audio Feedback:** Integrated dynamic sound queues and layered audio feedback to emphasize combat intensity, weapon handling, and impact responses.

---

## 🕹️ Project Overview

- **Genre:** Boomer Shooter / Rogue-Lite
- **Focus:** Technical Game Design, Combat Systems & Audio-Visual Feedback
- **Engine:** Unreal Engine 5
- **Status:** Active Development
